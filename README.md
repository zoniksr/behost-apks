# Restaurante Be nativo 0.6.0 · candidato QA

Cuatro aplicaciones Android nativas con diseño inspirado en Comedor Be. Hostess, Mesero, Cocina y Valet conservan identidad Android, almacenamiento cifrado, contratos del nodo y certificado QA de 0.5.0. Apariencia se configura exclusivamente dentro de Configuración. No contienen WebView.

Compiladas dos veces desde fuentes, con APK idénticas; ocho pruebas JVM pasadas, lint sin errores y cuatro APK de instrumentación compiladas. No se ejecutaron pruebas de interfaz en Android: el emulador local no inició el sistema y no hubo teléfonos físicos conectados. No hay capturas nativas verificadas de esta revisión. El APK es debuggable y usa el certificado QA existente; no se presenta como firma ni release de producción.

Versión 0.6.0-comedor-design-candidate, versionCode 6, mínimo Android API24, destinoAPI35. El canal estable permanece deshabilitado. Las APK se distribuyen desde GitHub; no se incluyen en el Implementador. Consulte el catálogo firmado de Restaurante Be para obtener los enlaces vigentes.

No se publica aquí código web propietario, credenciales, datos de usuarios ni claves de firma.
